# Reabilitação pós-mastectomia — site de apoio ao TCC

Site responsivo de apoio a um TCC de Fisioterapia sobre reabilitação domiciliar de mulheres após mastectomia. A proposta é uma **cartilha digital com vídeos**, com orientações, exercícios e autodrenagem organizados em fases.

O trabalho acadêmico é desenvolvido em documento próprio; o site é um recurso de apoio. O nome definitivo do produto ainda será escolhido.

## Estado do projeto

**Etapa atual: levantamento de requisitos.** Esta atualização registra as primeiras definições no README. A autorização atual se limita a este arquivo; não inicia desenvolvimento, prototipação, arquitetura detalhada ou provisionamento de infraestrutura.

## Conteúdo e responsabilidade clínica

O site não substitui avaliação ou acompanhamento profissional. A equipe clínica é responsável por revisar e aprovar indicações, exercícios, fases, repetições, frequência, cuidados, sinais de alerta e critérios de progressão.

A IA e a implementação técnica não devem inventar condutas clínicas nem critérios para avançar de fase. Uma sequência de fases não significa autorização para a paciente avançar sozinha.

O briefing inicial menciona mulheres adultas após mastectomia radical; o recorte clínico exato deverá ser conferido no TCC. A aplicabilidade dos roteiros de autodrenagem a diferentes condições linfáticas também precisa ser confirmada, sem assumir uma divisão já aprovada para o site.
